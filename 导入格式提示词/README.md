# 导入格式提示词

这个文件夹用于指导 AI 直接生成 **PromptPalette 可导入的预设 JSON**。

## 文件

- `AI生成预设提示词.md`：复制给 AI 的严格生成提示词。替换开头的主题、预设名、分类数量和标签数量即可。
- `preset.schema.json`：JSON Schema（Draft 2020-12），用于校验生成结果。

## 使用方式

1. 打开 `AI生成预设提示词.md`，把整段内容复制给 AI。
2. 替换提示词开头的变量（主题、预设名、数量等）。
3. AI 应只返回一个 JSON 对象；把它保存为 `任意名称.json`。
4. 在 PromptPalette 中点击 **导入**，选择该 JSON 文件。
5. 选择：
   - **创建为新预设**：保留文件里的完整词库，作为一个新预设。
   - **合并到已有预设**：分类/小分类按名称复用，标签按 `中文+English` 对合并归属。

## 标签身份规则

- 中文相同 + English 相同 = 同一个标签；导入时合并 `memberships`。
- 中文相同 + English 不同 = 两个不同标签。
- English 相同 + 中文不同 = 两个不同标签。
- 同一个标签可以同时属于多个分类/小分类；在文件里只需要写一个标签对象，并在 `memberships` 中列出多个路径。

## 合并规则

导入到已有预设时：

- 大分类按名称复用或新建。
- 小分类在同一大分类内按名称复用或新建。
- 标签按 `中文 + English` 识别；相同则把来源文件的归属并入已有标签，不相同则保留为不同标签。
- 因此合并后，同一个标签可以出现在多个分类中，并且始终会出现在应用的 **全部分类** 视图里。

## 完整示例

当前项目自带的完整预设位于：

```text
presets/AI绘画原子词典.ppreset.json
```

可以直接导入它作为完整示例。
