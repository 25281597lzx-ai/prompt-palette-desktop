# PromptPalette 预设生成 · 严格提示词

把下面整段提示词复制给任意支持长文本的 AI，替换开头的变量后使用。AI 的输出必须是一个可以直接导入 PromptPalette 的 JSON 文件。

---

你是一个“提示词预设数据生成器”。你的唯一任务是生成一个严格合法的 PromptPalette 预设 JSON 对象。

## 本次生成参数

- 主题：`{{主题，例如：赛博朋克女性角色}}`
- 预设名称：`{{预设名称，例如：赛博霓虹女性}}`
- 大分类数量：`{{例如：4}}`
- 每个大分类下的小分类数量：`{{例如：2-3}}`
- 标签总数：`{{例如：40}}`

如果用户没有提供某个参数，你可以自行给出合理值，但必须保持结构完整。

## 输出要求（最高优先级）

1. 只输出一个 JSON 对象。
2. 不要输出 Markdown 代码块、解释、前言、后记、注释、验证过程、Markdown 表格或任何 JSON 之外的字符。
3. 不要使用 `//`、`/* */` 或尾随逗号。
4. JSON 必须使用双引号；所有字符串必须正确转义。
5. 顶层必须且只能包含这 5 个字段：`format`、`version`、`name`、`categories`、`tags`。
6. `format` 必须精确等于 `prompt-palette-preset`。
7. `version` 必须精确等于数字 `1`。
8. 不要生成 `id`、`description`、`weight`、`color`、`icon`、`createdAt` 或任何未定义字段。
9. 输出必须能通过 RFC 8259 JSON 解析，并且能通过本文件夹中的 `preset.schema.json` 校验。

## 数据结构

顶层结构：

```json
{
  "format": "prompt-palette-preset",
  "version": 1,
  "name": "预设名称",
  "categories": [],
  "tags": []
}
```

`categories`：大分类数组，至少 1 个。
每个大分类对象必须且只能包含：

```json
{
  "name": "大分类名称",
  "subcategories": [
    { "name": "小分类名称" }
  ]
}
```

`tags`：标签数组，至少 1 个。
每个标签对象必须且只能包含：

```json
{
  "chinese": "中文标签",
  "english": "english prompt",
  "memberships": [
    { "category": "大分类名称", "subcategory": "小分类名称" }
  ]
}
```

## 命名与引用规则

1. 大分类名称不能为空，长度 1～40，整个预设内不能重复（忽略大小写和首尾空格）。
2. 小分类名称不能为空，长度 1～40，同一个大分类内不能重复（忽略大小写和首尾空格）。
3. 标签的 `chinese` 不能为空，长度 1～60；`english` 不能为空，长度 1～120。
4. 每个 `memberships` 至少 1 项，最多 100 项；每一项的 `category` 和 `subcategory` 必须精确指向 `categories` 中已经声明的大分类/小分类（可以忽略大小写，但输出时请使用完全一致的名称）。
5. 同一个标签不能重复声明同一个归属路径。
6. 不要创建空的 `categories`、空的 `subcategories` 或空的 `memberships`。
7. 所有名称使用去掉首尾空格后的最终文本；不要在名称中放换行、制表符或其他控制字符。

## 标签身份规则（必须严格执行）

标签的身份由 `chinese` 和 `english` 这一对值共同决定，比较时：

- 中文：去除首尾空格后精确比较。
- English：去除首尾空格后按不区分大小写比较。

因此：

- 中文相同且 English 相同 → 是同一个标签。整个 JSON 里只能出现一次，不能重复对象。
- 中文相同但 English 不同 → 是两个不同标签，必须输出两个独立对象。
- English 相同但中文不同 → 也是两个不同标签，必须输出两个独立对象。
- 即使两个标签语义相近，只要这一对值不完全相同，就保留为两个对象。

## 共享标签规则

一个标签可以同时属于多个分类/小分类。若同一个标签要出现在多个位置，必须：

- 只写一个标签对象；
- 在它的 `memberships` 中列出所有归属路径；
- 不要为同一个“中文+English”对重复写多个标签对象。

示例：同一标签同时出现在“人物 / 女性角色”和“镜头 / 景别”：

```json
{
  "chinese": "银发少女",
  "english": "silver-haired girl",
  "memberships": [
    { "category": "人物", "subcategory": "女性角色" },
    { "category": "镜头", "subcategory": "景别" }
  ]
}
```

## 内容要求

- 分类、小分类和标签必须围绕给定主题，语义合理，不要用重复的占位词凑数量。
- 中文标签简洁、可读；English 使用常见的 AI 图像提示词短语。
- 尽量覆盖人物、服装、表情、镜头、画风、光影、场景、质量等维度，但以主题为准。
- 不要输出负面提示词专用的额外结构；所有标签都按同一格式输出。
- 所有标签都必须至少有一个归属路径。
- 标签对象总数必须符合给定数量；如果无法精确满足，必须在内部自检时修正，而不是在 JSON 外说明。

## 数量与大小限制

- 大分类：1～100 个。
- 每个大分类的小分类：1～100 个。
- 标签：1～10000 个。
- 每个标签的 memberships：1～100 个。
- 名称、标签字段长度遵守上面的限制。

## 自检清单

在输出前逐项自检：

1. 是否只有 5 个顶层字段？
2. `format` 和 `version` 是否正确？
3. 是否所有大分类、小分类、标签非空？
4. 大分类名是否唯一？同一大分类内小分类名是否唯一？
5. 所有 memberships 是否都指向已声明路径？
6. 是否有同一个 `中文+English` 对被写成了两个标签对象？
7. 是否有“中文相同 English 不同”或“English 相同中文不同”的标签被错误合并？
8. 是否有标签缺少 memberships？
9. 是否是纯 JSON、没有 Markdown 代码块和注释？
10. 是否能被标准 JSON 解析器解析？

如果自检发现任何问题，请在内部修正后重新生成，不要在最终回答中解释。

现在，根据本次生成参数，直接输出唯一的、合法的 JSON 对象。
